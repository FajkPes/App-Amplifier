# App Amplifier

A Windows tool for boosting an individual app's audio while managing headroom.

## Key features

- Control amplification for a selected audio session.
- Use Equalizer APO for audio processing.
- Keep other application sessions separate.

## Get started

Download the ZIP from Releases and follow the Equalizer APO setup guide.
