# Release notes

## v1.0.0

- First public App Amplifier release.
- English is the default UI language; Czech remains available in settings.
- Renamed the executable and project files to English.
- Added a dependency-aware English launcher.
- Added a self-contained Windows x64 package with the .NET 8 runtime included.
- Preserved the legacy Equalizer APO include filename for upgrade compatibility.
- Added a safe `--check` startup mode that does not initialize system audio.
